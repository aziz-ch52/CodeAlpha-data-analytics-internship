## 📂 Projects & Tasks

This repository contains three independent projects based on the tasks assigned during the internship.

### 01. Web Scraping

**Objective:** Extract structured information from publicly accessible websites and transform it into usable datasets.

**Key Activities:**
- Understanding website HTML structures.
- Extracting relevant information using Python.
- Working with Requests and BeautifulSoup.
- Parsing and processing extracted data.
- Handling missing and inconsistent values.
- Exporting structured data into CSV format.

**Technologies:** Python, Requests, BeautifulSoup, Pandas.

📁 Project Folder: [`01_Web_Scraping`](./01_Web_Scraping/)

---

### 02. Exploratory Data Analysis (EDA)

**Objective:** Explore datasets to understand their structure, discover patterns, identify anomalies, and generate meaningful insights.

**Key Activities:**
- Understanding dataset structure and variables.
- Examining data types and statistical summaries.
- Identifying and handling missing values.
- Detecting duplicate records and outliers.
- Performing univariate and bivariate analysis.
- Exploring relationships between variables.
- Analyzing trends and patterns.
- Creating visualizations to validate observations.
- Documenting analytical findings.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn.

📁 Project Folder: [`02_Exploratory_Data_Analysis`](./02_Exploratory_Data_Analysis/)

---

### 03. Data Visualization

**Objective:** Transform analyzed datasets into meaningful visual representations and dashboards that communicate insights effectively.

**Key Activities:**
- Preparing and transforming datasets.
- Identifying relevant business KPIs.
- Creating charts and graphs.
- Designing interactive dashboards.
- Developing meaningful data comparisons.
- Presenting trends and performance indicators.
- Communicating insights through data storytelling.
- Documenting business findings and recommendations.

**Technologies:** Python, Pandas, Matplotlib, Seaborn, Microsoft Power BI, DAX.

📁 Project Folder: [`03_Data_Visualization`](./03_Data_Visualization/)
