# Global E-Commerce Sales: Data Visualization & Dashboarding

## 📌 Project Overview
This repository contains a comprehensive Data Visualization and Business Intelligence pipeline for global e-commerce sales data. Developed as part of a **Data Analytics Internship at CodeAlpha**, this project demonstrates the ability to translate processed data into compelling visual narratives and interactive dashboards.

The workflow bridges the gap between programmatic statistical plotting in Python (**Matplotlib**, **Seaborn**) and enterprise-level interactive dashboarding using **Microsoft Power BI**, culminating in actionable business recommendations.

---

## 🔍 Visualization & BI Workflow
* **Data Preparation:** Loaded raw global sales data, handled missing values, standardized formats, and exported a visualization-ready dataset (`cleaned_ecommerce_sales.csv`) to isolate the BI pipeline from the raw ingestion layer.
* **Matplotlib Core Visualizations:** Developed foundational, cleanly formatted business charts (e.g., Monthly Global Revenue Trends) focusing on precise structural aesthetics and temporal analysis.
* **Seaborn Advanced Visualizations:** Engineered complex statistical plots, including categorical revenue boxplots (to spot extreme high-value outliers) and feature correlation heatmaps, utilizing a muted, professional color palette.
* **Power BI Dashboarding:** Ingested the processed data into Power BI to build an interactive executive dashboard. Authored custom DAX measures (`Total Revenue`, `Profit Margin %`, `AOV`) to enable dynamic slicing by financial quarter and product category.
* **Strategic Reporting:** Translated visual findings into direct business recommendations targeting discount strategy optimization and inventory seasonality.
